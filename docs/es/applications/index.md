# Aplicaciones y Formulación

**TL;DR** — El pimentón y los chiles secos cumplen dos trabajos distintos en los alimentos: el
pimentón colorea, el chile pica. Muchas formulaciones combinan ambos — pimentón para un rojo
estable, chile para el perfil de picor objetivo. Ajustar la variedad correcta al trabajo es lo que
separa un producto consistente de uno variable.

## Dónde Se Usa el Pimentón

El papel principal del pimentón es la coloración roja natural, con sabor suave:

- **Mezclas de especias y condimentos** — color y calidez suave
- **Adobos y aliños de carne** — color con aroma claro de chile
- **Embutidos y carne procesada** — coloración roja natural
- **Condimentos de snacks y fideos instantáneos** — base de color
- **Extracción de oleorresina de pimentón** — la materia prima del colorante rojo natural

## Dónde Se Usan los Chiles Secos

Los chiles secos añaden picor, con el color como beneficio secundario:

- **Salsas picantes y aceite de chile** — polvo u hojuelas de alto picor
- **Condimentos de snacks** — polvo de alto picor para el golpe
- **Mezclas de condimentos** — nivel de picor ajustado al perfil objetivo
- **Food service y hot-pot** — chiles secos enteros para picor visible
- **Carne procesada y adobos** — picor medio y aroma

## La Combinación Color + Picor

El patrón de formulación más útil es combinar pimentón y chile:

| Objetivo | Uso |
|---|---|
| Rojo estable, sin picor | Solo pimentón dulce |
| Rojo + calidez suave | Pimentón de bajo picor |
| Picor con algo de color | Chile en polvo de alto picor |
| Picor + color, por capas | Pimentón (color) + mezcla de chile (picor) |

Una mezcla de chile en sí suele combinar varias variedades — una de alto picor para el golpe, una
media para el cuerpo y un pimentón de alto color para el atractivo visual. Este enfoque de "picor
y color por capas" es cómo se construyen las salsas picantes y condimentos consistentes.

## Un Ejemplo Trabajado: Adobo Picante

Para concretar el principio, aquí hay un adobo representativo con chile dominante construido por
capas — cada ingrediente tiene un trabajo, y el chile no es una sola variedad sino una mezcla de tres:

| Ingrediente | Partes | Papel en la mezcla |
|---|---|---|
| Sal | 35 | Sazonado base, textura |
| Glutamato monosódico | 20 | Cuerpo umami |
| Azúcar | 7 | Equilibrio dulce |
| Chile Jixin (corazón de pollo) | 11 | Golpe de alto picor (50,000+ SHU) |
| Chile Xiaomi | 7 | Picor + realce de aroma |
| Yidu red (tipo pimentón de bajo picor) | 5 | Color + profundidad suave |
| Cebolla en polvo | 4 | Redondez sabrosa |
| Ajo en polvo | 2 | Aroma |
| Pimienta negra | 1 | Mordida aguda en la lengua (piperina) |

El patrón es el punto: un chile picante para el golpe, un chile medio para el realce, un pimentón
colorante para el rojo, y pimienta para la mordida en la lengua. Así es como un formulador
construye picor por capas en lugar de una sola nota. Consulte
[percepción del picor](../heat-perception/index.md) para por qué el chile y la pimienta golpean
receptores distintos.

*Nota: esta es una formulación ilustrativa que muestra el principio de capas. Trabaja con tu
proveedor para ajustar las proporciones exactas a tu perfil objetivo de picor y color.*

## Notas de Formulación

- **El picor no es lineal** — una pequeña cantidad de chile extra picante (50,000+ SHU) mueve el
  picor de una mezcla mucho más que el mismo peso de chile medio.
- **El color es la base** — para rojo estable en estantería, especifica el ASTA del pimentón y
  confirma la esterilización, ya que el color cambia en almacenamiento (ver
  [color ASTA y SHU explicados](../asta-shu-explained/index.md)).
- **La malla afecta la liberación** — el polvo más fino libera color y picor más rápido que las hojuelas gruesas.
