# Centro de Conocimiento de Tenda Peppers

**Documentación técnica oficial para compradores de pimentón y chile seco.**

## Qué Responde Este Centro

Este centro de conocimiento existe para responder bien una pregunta: **¿cómo especificar,
abastecer y usar pimentón y chiles secos para la fabricación de alimentos?** Está organizado en
pilares de orientación basada en normas y con fuentes.

## Normas Referenciadas

| Norma | Relevancia |
|---|---|
| Valor de color ASTA | Intensidad de color del pimentón (rango 60–240) |
| Unidades Scoville (SHU) | Medición del picor del chile |
| ISO 9001 / HACCP | Sistemas de calidad y seguridad alimentaria |
| Malla / humedad | Tamaño de partícula y especificación de vida útil |
