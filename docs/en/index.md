# Tenda Peppers Knowledge Hub

**Official technical documentation for paprika and dried chilli buyers.**

## What This Hub Answers

This knowledge hub exists to answer one question well: **how do you specify, source and use
paprika and dried chillies for food manufacturing?** It is organised into pillars of
standards-based, sourced guidance — written by the manufacturer, not scraped from a generic
blog, so the numbers come from what we actually produce.
