# Шаблоны Спецификации Покупателя

**TL;DR** — Скопируйте блок вашей формы продукта, замените каждую скобку целевым
значением и отправьте с запросом. Полная спецификация называет сорт (или окно SHU),
происхождение, форму, помол, влажность, активность воды, SHU, цвет ASTA и параметры
безопасности для вашего рынка — затем проверьте COA конкретной партии.

## Шаблон 1 — Порошок чили

```
Продукт:          Порошок чили
Сорт:             [Sanying / Zidantou / Jixin — или только окно SHU]
Происхождение:    [Shandong]
Окно SHU:         [20,000–50,000]
ASTA:             [≥100]
Помол:            [60–80 mesh]
Влажность:        [≤13%]
Активность воды:  [≤0.65]
Безопасность:     [лимиты ЕС по афлатоксинам · пестициды · микробиология по рынку]
Упаковка:         [крафт-мешки 25 кг, экспортные коробки]
Документы:        [COA партии · сертификаты безопасности · прослеживаемость]
```

```
ASTA:           [целевое значение]

```

```
Продукт:        Порошок паприки (сладкая / низкой остроты)

Происхождение:  [Xinjiang / Shandong]
ASTA:           [60–240 — подтвердите цель]

Помол:          [60–80 mesh]
Влажность:      [≤13%]
Безопасность:   [афлатоксины · пестициды · микробиология по рынку]
Упаковка:       [крафт-мешки 25 кг, экспортные коробки]
Документы:      [COA партии · сертификаты · прослеживаемость]
```

## Пустой шаблон — любая форма

```
Продукт:          [целый / хлопья / порошок / сегменты]
Сорт:             [название или окно SHU]
Происхождение:    [провинция]
Окно SHU:         [–]
ASTA:             [–]
Помол:            [20–40 хлопья · 60–80 порошок · 100+ соусы]
Влажность:        [≤13%]
Активность воды:  [≤0.65]
Безопасность:     [лимиты рынка]
Упаковка:         [тип мешка, вес]
Документы:        [COA партии · сертификаты · прослеживаемость]
```

## Почему письменная спецификация окупает себя

Острота, цвет, текстура, безопасность и срок хранения дрейфуют сами по себе, когда не
заданы. Спецификация в одну строку ничего не стоит написать и спасает от провальной
партии — покупатели, получающие стабильный продукт, это те, кто задаёт всё и затем
проверяет COA партии.

## Какие документы требовать

COA конкретной партии (SHU, ASTA, влажность, микробиология, пестициды, микотоксины),
сертификаты безопасности и прослеживаемость до базы выращивания. Общий каталожный
сертификат — не COA партии.

> Значения в скобках — репрезентативные примеры из нашего гайда по покупке — подтвердите
> ваши точные SHU, ASTA, влажность и рыночные лимиты до заключения договора.
