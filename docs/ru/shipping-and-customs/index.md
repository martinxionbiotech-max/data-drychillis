# Доставка и таможня для импорта паприки и чили

**Кратко** — доставляйте оптовые заказы морем, малые или срочные — авиа. Подготовьте комплект
таможенных документов до прибытия товара — инвойс, упаковочный лист, коносамент, сертификаты и
COA — и выберите Инкотерм, соответствующий тому, сколько контроля над доставкой вы хотите.
Сушёный чили легко доставлять: нет холодовой цепи, только контроль влажности.

## Морская против авиа доставки

Первое логистическое решение — метод транспортировки. Всё сводится к стоимости против скорости:

| Фактор | Морская доставка | Авиа доставка |
|---|---|---|
| Стоимость за кг | Низкая — стандарт для опта | Высокая — надбавка за скорость |
| Время в пути | Недели | Дни |
| Лучше всего для | Полноконтейнерные оптовые заказы, регулярные поставки | Образцы, малые заказы, срочное пополнение |
| Минимальный объём | Подходит для крупных партий | Экономична только при малых объёмах |

Для большинства пищевых производителей картина ясна: **морская доставка для производственных
поставок, авиа — для образцов и срочных пробелов**. Сушёная паприка и чили — плотные, стабильные
при хранении товары, которые хорошо хранятся в контейнере, что делает морскую доставку стандартом
для регулярных заказов.

## Чек-лист таможенных документов

Полный комплект импортных документов делает таможенную очистку гладкой. Для сушёной паприки и
чили типичный комплект включает:

| Документ | Назначение |
|---|---|
| Коммерческий инвойс | Стоимость и условия продажи |
| Упаковочный лист | Количества, веса и разбивка по упаковкам |
| Коносамент (или авианакладная) | Доказательство отгрузки и перевозчик |
| Сертификат происхождения | Подтверждает страну происхождения для тарифного режима |
| Санитарный сертификат | Подтверждение безопасности пищи |
| Фитосанитарный сертификат | Подтверждение растительного продукта (чили — растительный продукт) |
| Сертификат анализа (COA) | Результаты цвета, остроты и влажности на уровне партии |
| Спецификационный лист | Согласованные сорт, SHU, ASTA, помол и влажность |

Требования различаются по стране назначения, поэтому подтверждайте точный комплект с поставщиком
и экспедитором до отгрузки товара. О том, как строятся спецификационный лист и COA, см.
[руководство по закупке](../buying-guide/index.md).

## Объяснение Инкотермс

Инкотермс определяют, кто платит за и контролирует каждый участок отгрузки. Самые
распространённые для импорта чили:

| Инкотерм | Что обрабатывает продавец | Роль покупателя |
|---|---|---|
| **EXW** (Ex Works) | Товар только у ворот завода | Покупатель организует всё ниже по цепочке |
| **FOB** (Free On Board) | Товар погружен на судно | Покупатель организует фрахт + страховку |
| **CIF** (Cost, Insurance, Freight) | Фрахт и страховка до порта назначения | Покупатель очищает таможню и принимает товар |
| **DAP / DDP** (Delivered) | Продавец доставляет до пункта назначения (DDP включает пошлину) | Покупатель получает товар |

FOB и CIF — рабочие лошадки для импорта чили. Выбирайте FOB, если у вас есть предпочтительный
экспедитор и вы хотите контроль над фрахтом; выбирайте CIF, если хотите, чтобы продавец управлял
морским участком. О последствиях для MOQ и сроков поставки см. [«Импорт и цепочка поставок»](../importing/index.md).

## Почему сушёный чили легко доставлять

Сушёная паприка и чили — одни из самых простых пищевых продуктов для импорта:

- **Нет холодовой цепи** — они стабильны при хранении при комнатной температуре
- **Контроль влажности** — влажность ниже 13% сохраняет их стабильными в пути (см.
  [«Изменение цвета и хранение»](../colour-storage/index.md))
- **Герметичная упаковка** — защищает от влажности во время океанского пути

Единственное, что нужно сделать правильно — влажность. Сухой, хорошо запечатанный продукт
прибывает в том же состоянии, в котором покинул завод.
