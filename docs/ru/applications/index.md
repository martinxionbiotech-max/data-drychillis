# Применение и рецептуры

**Кратко** — паприка и сушёный чили выполняют две разные задачи в пище: паприка окрашивает, чили
придаёт остроту. Многие рецептуры сочетают оба — паприку для стабильного красного цвета, чили для
целевого профиля остроты. Подбор правильного сорта под задачу — то, что отделяет постоянный
продукт от изменчивого.

## Где используется паприка

Основная роль паприки — натуральное красное окрашивание, с мягким вкусом:

- **Смеси специй и приправ** — цвет и мягкое тепло
- **Маринады и мясные натирки** — цвет с ясным ароматом чили
- **Колбасы и переработанное мясо** — натуральное красное окрашивание
- **Приправы для снеков и лапши быстрого приготовления** — цветовая основа
- **Экстракция олеорезина паприки** — сырьё для натурального красного пищевого красителя

## Где используется сушёный чили

Сушёный чили добавляет остроту, с цветом как вторичным преимуществом:

- **Острые соусы и масло чили** — высокоострый порошок или хлопья
- **Приправы для снеков** — высокоострый порошок для удара
- **Смеси приправ** — уровень остроты под целевой профиль
- **Общепит и хот-пот** — целый сушёный чили для видимой остроты
- **Переработанное мясо и маринады** — средняя острота и аромат

## Сочетание цвета + остроты

Самый полезный шаблон рецептуры — сочетание паприки и чили:

| Цель | Использование |
|---|---|
| Стабильный красный цвет, без остроты | Только сладкая паприка |
| Красный цвет + мягкое тепло | Слабоострая паприка |
| Острота с некоторым цветом | Порошок высокоострого чили |
| Острота + цвет, многослойно | Паприка (цвет) + смесь чили (острота) |

Смесь чили сама часто наслаивает несколько сортов — высокоострый сорт для удара, средний сорт для
тела и высокоцветную паприку для визуальной привлекательности. Этот подход «многослойной остроты
и цвета» — то, как строятся постоянные острые соусы и приправы.

## Рабочий пример: пряный маринад

Чтобы сделать принцип конкретным, вот представительный маринад с акцентом на чили, построенный
многослойным способом — у каждого ингредиента есть задача, а чили — не один сорт, а смесь трёх:

| Ингредиент | Части | Роль в смеси |
|---|---|---|
| Соль | 35 | Базовая приправа, текстура |
| Глутамат натрия | 20 | Тело умами |
| Сахар | 7 | Сладкий баланс |
| Jixin (chicken-heart) чили | 11 | Высокоострый удар (50 000+ SHU) |
| Xiaomi чили | 7 | Острота + подъём аромата |
| Yidu red (слабоострый тип паприки) | 5 | Цвет + мягкая глубина |
| Луковый порошок | 4 | Пикантная округлость |
| Чесночный порошок | 2 | Аромат |
| Чёрный перец | 1 | Резкий укус языка (пиперин) |

Суть в шаблоне: острый чили для удара, средний чили для подъёма, красящая паприка для красного и
перец для укуса языка. Так разработчик строит остроту, которая многослойна, а не однотонна. См.
[«Восприятие остроты чили»](../heat-perception/index.md), почему чили и перец воздействуют на
разные рецепторы.

*Примечание: это иллюстративная рецептура, показывающая принцип наслоения. Работайте с
поставщиком, чтобы подобрать точные соотношения под вашу целевую остроту и цвет.*

## Замечания по рецептуре

- **Острота нелинейна** — небольшое количество экстра-острого чили (50 000+ SHU) меняет остроту
  смеси гораздо сильнее, чем тот же вес среднего чили.
- **Цвет — основа** — для стабильного при хранении красного задавайте ASTA паприки и подтверждайте
  стерилизацию, поскольку цвет меняется при хранении (см. [«Объяснение цвета ASTA и SHU»](../asta-shu-explained/index.md)).
- **Помол влияет на высвобождение** — более мелкий порошок высвобождает цвет и остроту быстрее,
  чем крупные хлопья.
