# Центр знаний Tenda Peppers

**Официальная техническая документация для закупщиков паприки и сушёного чили.**

**Кратко** — этот центр отвечает на один вопрос: как задать спецификацию, закупить и
использовать паприку и сушёный чили в пищевом производстве? Паприку указывают по цвету
(ASTA) и мягкой остроте; сушёный чили — по остроте (SHU) и форме продукта. Каждая цифра
взята из того, что реально производит изготовитель, а не скопирована из случайного блога.

## На что отвечает этот центр

Этот центр знаний существует, чтобы хорошо ответить на один вопрос: **как задать спецификацию,
закупить и использовать паприку и сушёный чили в пищевом производстве?** Он организован по
разделам стандартизированных, подтверждённых источниками руководств — написан самим
производителем, а не скопирован из общего блога, поэтому цифры берутся из того, что мы реально
производим.

## Стандарты, на которые ссылаемся

| Стандарт | Значение |
|---|---|
| Значение цвета ASTA | Интенсивность цвета паприки (диапазон 60–240) |
| Единицы остроты Сковилла (SHU) | Измерение остроты чили |
| Капсаицин (C16H27NO3) | Соединение, отвечающее за остроту чили |
| ISO 9001 / HACCP | Системы качества и безопасности пищевых продуктов |
| Помол / влажность | Спецификация размера частиц и срока годности |
