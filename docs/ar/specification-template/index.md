# قوالب مواصفات المشتري

**TL;DR** — انسخ كتلة شكل منتجك، واستبدل كل قوس بقيمتك المستهدفة، وأرسلها مع استفسارك.
المواصفة الكاملة تذكر الصنف (أو نافذة SHU) والمنشأ والشكل والشبكة والرطوبة ونشاط الماء
وSHU ولون ASTA ومعايير سلامة الغذاء لسوقك — ثم تحقق بـCOA خاص بالدفعة.

## القالب 1 — مسحوق الفلفل

```
المنتج:        مسحوق الفلفل
الصنف:        [سانينغ / زيدانتو / جيشين — أو اذكر نافذة SHU فقط]
المنشأ:       [شاندونغ]
نافذة SHU:    [20,000–50,000]
ASTA:         [≥100]
الشبكة:       [60–80 شبكة]
الرطوبة:      [≤13%]
نشاط الماء:   [≤0.65]
سلامة الغذاء: [حدود الاتحاد الأوروبي للأفلاتوكسين · مبيدات · ميكروبي حسب السوق]
التعبئة:      [أكياس كرافت 25 كجم، كراتين تصدير]
المستندات:    [COA خاص بالدفعة · شهادات سلامة الغذاء · تتبع]
```

## القالب 2 — رقائق الفلفل / المجروش

```
المنتج:        رقائق الفلفل / الفلفل المجروش
الصنف:        [جينتا / شيان — رقائق مرئية، لون زاهٍ]
المنشأ:       [قانسو]
نافذة SHU:    [10,000–20,000]
ASTA:         [القيمة المستهدفة]
الشبكة:       [20–40 شبكة]
الرطوبة:      [≤13%]
سلامة الغذاء: [أفلاتوكسين · مبيدات · ميكروبي حسب السوق]
التعبئة:      [أكياس كرافت / كراتين، حاجز رطوبة]
المستندات:    [COA خاص بالدفعة · شهادات · تتبع]
```

## القالب 3 — مسحوق البابريكا

```
المنتج:        مسحوق البابريكا (حلوة / منخفضة الحرارة)
الصنف:        [فلفل شينجيانغ الحلو / ييدو الأحمر، وانغدو]
المنشأ:       [شينجيانغ / شاندونغ]
ASTA:         [60–240 — أكّد الهدف]
SHU:          [<500 حلوة · <10,000 منخفضة الحرارة]
الشبكة:       [60–80 شبكة]
الرطوبة:      [≤13%]
سلامة الغذاء: [أفلاتوكسين · مبيدات · ميكروبي حسب السوق]
التعبئة:      [أكياس كرافت 25 كجم، كراتين تصدير]
المستندات:    [COA خاص بالدفعة · شهادات · تتبع]
```

## قالب فارغ — أي شكل

```
المنتج:        [كامل / رقائق / مسحوق / قطع]
الصنف:        [الاسم أو نافذة SHU]
المنشأ:       [المقاطعة]
نافذة SHU:    [–]
ASTA:         [–]
الشبكة:       [20–40 رقائق · 60–80 مسحوق · 100+ صلصات]
الرطوبة:      [≤13%]
نشاط الماء:   [≤0.65]
سلامة الغذاء: [حدود السوق]
التعبئة:      [نوع الكيس، الوزن]
المستندات:    [COA خاص بالدفعة · شهادات · تتبع]
```

## لماذا تدفع المواصفة المكتوبة ثمنها بنفسها

الحرارة واللون والملمس والسلامة ومدة الصلاحية ينحرف كل منها وحده عندما لا يُحدد.
مواصفة من سطر واحد لا تكلف شيئًا لكتابتها وتجنبك دفعة فاشلة — المشترون الذين يحصلون
على منتج متسق هم الذين يحددون كل شيء ثم يتحققون بـCOA دفعة.

## ما المستندات التي يجب طلبها

COA خاص بالدفعة (SHU وASTA والرطوبة والميكروبي والمبيدات والسموم الفطرية)، وشهادات
سلامة الغذاء، والتتبع حتى قاعدة الزراعة. شهادة الكتالوج العامة ليست COA دفعة.

> القيم بين الأقواس أمثلة تمثيلية من دليل الشراء — أكّد SHU وASTA والرطوبة وحدود السوق
> بدقة قبل التعاقد.
